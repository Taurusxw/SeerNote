# SeerNote 1.8.0 发布说明

发布日期：2026-08-24

目标平台：Windows 11 / .NET Framework 4.8

## 用户可见变化

- 搜索框在存在查询时直接显示“清空搜索”，结果列表支持 `Enter` 进入正文、`Esc` 清空并返回搜索框，鼠标、键盘和辅助技术用户共享同一闭环。
- 用户动作结果接入 WPF UI Automation live region：普通反馈使用 `Polite`，可恢复错误使用 `Assertive`，自动保存过程保持静默。
- 大 Note 集合改用 WPF 回收式虚拟化；分类侧栏和 Note 右键菜单按可见容量自适应，避免为不可见项目预建完整控件树。

## 响应性改进

- 筛选结果、导航计数和分类选择器复用稳定快照；纯选择、正文输入和搜索切换只刷新真实依赖项。
- 分类行、分类菜单和 Note 菜单复用稳定结构，同时在打开时冻结精确业务目标，避免选择变化导致命令作用于错误 Note。
- 清空回收站改为单次线性稳定压缩。25000 条、交错删除 50% 的同机基准由 `262.9163 ms` 降至 `0.2439 ms`，线程分配由 `263480 B` 降至 `944 B`；全部九个测量场景均为正向收益。

## 兼容与升级

- 数据 schema、CLI `seernote.cli.v1` / `seernote.note.v1` 契约、原子保存、备份、恢复和工作区锁均未改变，无需迁移数据。
- 升级前先正常退出 SeerNote 并备份便携目录；用新 ZIP 中的程序和 `fonts/` 覆盖应用文件，保留原 `data/` 目录。
- 无账号、网络、遥测、安装器、NuGet 或第三方运行时 DLL；源码继续采用 MIT，思源黑体继续采用 SIL Open Font License 1.1。

## 分发说明

- 首选资产是 `SeerNote-portable-v1.8.0.zip`，包含桌面端、CLI、图标、私有字体、字体许可证、MIT 许可证和 README。
- 发布页同时提供双 EXE 与 `SHA256SUMS.txt`。当前程序未使用商业代码签名证书，Windows SmartScreen 可能显示未知发布者；请从项目官方 Release 下载并校验 SHA-256。
