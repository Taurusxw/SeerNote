# SeerNote 1.6.1 发布说明

发布日期：2026-08-23

目标平台：Windows 11 / .NET Framework 4.8

## 用户可见变化

- “复制正文”从编辑区顶部命令栏移动到底部“智能体交接”组。
- 底部交接顺序统一为“复制正文、复制 ID、复制为 JSON”；删除或恢复操作继续独立位于右侧。
- 顶部命令栏只保留分类、收藏和置顶小窗。

## 保持不变

- `Ctrl+Enter`、`{{变量}}` 填写、剪贴板重试和状态栏反馈不变。
- 回收站 Note 仍不能复制正文，但可复制稳定 ID 和 JSON。
- CLI、存储 schema、原子保存、备份、恢复、工作区锁和第三方依赖边界均未变化。

构建、渲染与根目录便携发布均已通过；两个根 EXE 已更新为 `1.6.1.0`。详见 [ACCEPTANCE.md](ACCEPTANCE.md)。
