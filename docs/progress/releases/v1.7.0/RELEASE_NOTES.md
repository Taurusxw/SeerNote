# SeerNote 1.7.0 发布说明

发布日期：2026-08-23

目标平台：Windows 11 / .NET Framework 4.8

## 用户可见变化

- 桌面端升级为更清晰的智能体友好工作台：搜索范围、快捷键、本地保存状态、导航数量和分类数量持续可见。
- “新建”降为次级操作，“复制正文”保持活动 Note 唯一实心主操作；ID/JSON 交接和危险操作继续分区。
- 收藏使用金色状态，按钮、输入框、列表行、滚动条与组合框采用统一克制的交互语法。
- 紧凑、标准、宽屏和超宽四档三栏布局适配 1080p、1200p、2K 与 4K 工作区，最小窗口仍保持正文和底部动作可达。

## 保持不变

- 本地便携数据、CLI 契约、`Ctrl+Enter`、变量填写、回收站与永久删除边界不变。
- 无账号、网络、遥测、安装器、NuGet 或第三方运行时 DLL。
- 高对比模式仍服从 Windows，标准 WPF 文本控件继续负责中文 IME、选择、撤销和辅助技术。

构建、测试、真实渲染、可见窗口交互和根目录便携发布均已通过；两个根 EXE 已更新为 `1.7.0.0`。详见 [ACCEPTANCE.md](ACCEPTANCE.md)。
