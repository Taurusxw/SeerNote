# Changelog

## 1.7.0 — 2026-08-23

### Changed

- 将桌面端收敛为更适合人和智能体共同工作的三栏工作台：搜索显示图标、范围提示与 `Ctrl+F` 徽标，标题旁持续显示本地保存真相，底部交接区保留唯一实心主操作“复制正文”。
- 统一按钮、输入框、列表行、滚动条与组合框的 WPF 语义模板，新增工具栏、导航和危险动作角色；悬停、按下、焦点与选中状态不再改变控件几何。
- 系统导航与自定义分类显示实时数量，长分类名不再触发横向滚动；收藏采用金色状态，删除/恢复继续与高频动作隔离。
- 细化紧凑、标准、宽屏和超宽四档三栏宽度，在最小、默认、1080p、1200p、2K 与 4K 工作区保持编辑画布和底部交接动作可达。

### Verified

- 六组自动化测试全部通过；真实 WPF 渲染覆盖六档尺寸、活动/回收站/空状态和石墨、午夜、Win11 雾白、鼠尾草四主题。
- 可见窗口检查确认 `Ctrl+N` 创建并聚焦标题、设置窗口与 UI Automation 名称/说明可用；发布仍为零第三方 DLL、零网络与同目录便携数据。

## 1.6.1 — 2026-08-23

### Changed

- 将“复制正文”从标题下方命令栏移动到编辑区底部“智能体交接”组，并置于“复制 ID / 复制为 JSON”之前，让三种交接方式集中在同一位置。
- 顶部命令栏只保留分类、收藏和置顶小窗；`Ctrl+Enter`、变量填写、复制反馈及回收站中的可用性边界保持不变。
- 底部复制按钮采用紧凑内边距，在 `860×540` 最小窗口、默认、2K 和回收站布局中保持可达，删除/恢复区继续独立位于右侧。

## 1.6.0 — 2026-08-22

### Added

- 新增零依赖 `SeerNote.Cli.exe`，提供 `schema`、`categories`、`list`、`get`、`create`、`update`、`delete` 和 `restore` 命令。
- CLI 成功时向 stdout 输出单个 `seernote.cli.v1` JSON 对象，失败时向 stderr 输出结构化错误；退出码区分用法、未找到、工作区占用、校验和存储失败。
- 新增 `seernote.note.v1` 结构化 Note 契约，统一桌面“复制为 JSON”和 CLI 的字段、UUID 与 UTC 时间戳格式。
- 桌面编辑区底部新增“智能体交接”组，可复制 Note ID 或 JSON；右键菜单同步提供，回收站 Note 仍可使用。

### Changed

- 删除、还原与永久删除继续独立位于底部右侧，与左侧智能体交接操作分区；顶部“复制正文”和 `Ctrl+Enter` 保持不变。
- 所有 CLI 数据命令与桌面端共享 `data/.seernote.lock`；读取也先加锁，以覆盖启动恢复可能产生的写入。
- 发布结构扩展为同目录的 `SeerNote.exe` 与 `SeerNote.Cli.exe`，仍不引入第三方 DLL、安装器、网络或遥测。

### Safety

- CLI `delete` 只移入回收站，不提供永久删除命令；恢复路径仍由现有原子 JSON、备份和校验实现负责。

## 1.5.0 — 2026-08-21

### Added

- 主窗口新增工作区感知的首次启动尺寸，在 1080p、1200p、2560×1440 和 3840×2160 可用工作区间按比例增长，并限制在 `1080×720` 至 `1920×1280` DIPs。
- 三栏新增紧凑、标准、宽屏和超宽四档内容断点；用户缩放窗口时，分类栏和 Note 列表即时调整，编辑区保留明确的最低可用宽度。

### Changed

- Per-Monitor V2 继续负责 100%–200% DPI 像素映射；布局以逻辑 DIPs 判断，不按物理分辨率重复放大字体或控件。
- 已保存的有效用户窗口边界继续优先恢复；自适应默认值不会覆盖用户手动选择的窗口大小。

## 1.4.0 — 2026-08-18

### Changed

- 右侧编辑区吸收 Windows 11 记事本的层级与密度：标题成为当前 Note 标签，分类、收藏、复制和置顶小窗进入紧凑命令栏，正文改为大面积无边框纯文本画布。
- 删除、还原和永久删除保留在独立底栏，不与高频编辑命令混排；最小 `860×540` 窗口下命令栏会有序换行，正文仍保持可用尺寸。
- 原“雾白”主题调整为“Win11 雾白”，使用浅灰蓝外壳、白色编辑纸面和轻边框；主题总数仍为四个，没有增加皮肤、富文本、账户或伪标签页功能。
- 应用图标简化为青绿色圆角底板、暖白便签、焦点圆和金色折角，减少小尺寸下的黑框、眼形细节与高光噪声；ICO 继续包含 `16–256 px` 七档图像。
- 界面、Note 正文与置顶小窗测量统一使用应用私有的思源黑体 CN Regular，改善简体中文、英文和数字混排时的字形与换行一致性。
- 字体与 OFL 许可证随 `fonts/` 目录发布，不安装到 Windows；字体缺失或损坏时回退系统字体并显示可恢复状态。

## 1.3.0 — 2026-08-18

### Added

- 置顶小窗新增内容驱动的自适应尺寸算法：短正文使用 `320×180` 最小尺寸，中长正文按实际中文换行测量扩展，最大不超过 `720×640`，并继续受工作区可用尺寸约束。
- 当全文无法在最大阈值内显示时，小窗选择纵向溢出最少的宽度并启用原有垂直滚动；不会出现横向滚动。

### Changed

- 每次打开置顶小窗会保留位置并按当前标题、正文重新计算尺寸；正文编辑采用合并调度重新适配，避免每次按键重复布局。
- 用户在当前打开会话中手动调整小窗后，将优先保留手动尺寸，避免继续输入时窗口与用户争夺大小。

## 1.2.2 — 2026-08-18

### Fixed

- 修复打开包含分隔线的 Note 右键菜单时出现“用于类型 MenuItem 的样式不能应用于类型 Separator”并触发未处理错误的问题。
- 根菜单、菜单栏和任意层级子菜单现在按真实容器类型分别选择 `MenuItem` 与 `Separator` 样式，继续保持统一主题且不再强制套用错误类型。

## 1.2.1 — 2026-08-18

### Fixed

- 修复左侧导航与分类点击时因焦点边框、字体粗细变化和分类行重建造成的版式抖动；分类序列不变时会原位更新数量和选中状态。
- 移除正文上方常驻的“变量占位”提示，保留正文中的 `{{变量}}` 自动识别与复制填写能力。

### Changed

- 窗口内所有当前及未来的 WPF 菜单统一由一套主题模板管理，覆盖右键菜单、任意层级子菜单、图标/勾选列、分隔线、悬停、键盘高亮和禁用状态。
- 托盘菜单跟随当前主题的语义配色；Windows 高对比模式继续使用系统渲染。
- 删除已被统一菜单系统取代的旧菜单样式、动态选中字体粗细和旧变量提示代码，不新增依赖或额外运行时文件。

## 1.2.0 — 2026-08-18

### Added

- 左侧新增有序自定义分类，可创建、重命名、删除并拖拽排序；Note 可拖到分类中移动。
- Note 列表新增右键菜单，提供复制、收藏、置顶小窗、移动分类和回收站操作；回收站中提供还原与永久删除。
- 设置中的“主题风格”和“关闭按钮行为”改为带当前值摘要的二级折叠组。

### Changed

- 随手记与提示词合并为统一 Note，只保留一个“新建条目”入口；所有 Note 都会按正文自动识别 `{{变量}}`。
- 左侧“收藏置顶”移动到首位，其后为“所有条目”、自定义分类和回收站。
- 编辑区移除类型选择器，分类选择和收藏操作改为带标签的紧凑布局；下拉菜单和右键菜单统一使用应用主题。

### Migration

- 便携数据升级为 `schemaVersion: 2`，新增有序 `categories`；首次读取版本 1 时自动保留全部正文、收藏、分类和置顶小窗状态，旧类型与旧类型视图迁移为统一 Note/所有条目。
- 新版本首次保存仍走原子替换并生成旧主文件备份；版本 1 数据不会被就地静默覆盖。

## 1.0.2 — 2026-08-18

### Fixed

- 提示词视图的空状态改用 `Ctrl+Shift+N` 和提示词文案，空状态按钮会创建提示词而不是随手记。
- 右侧空编辑区会随当前视图显示对应的随手记或提示词引导。
- 侧栏导航改用专用按钮模板，悬停和键盘焦点仅显示边框，不再形成浅蓝色的第二选中块。

- 彻底退出会同步保存并释放托盘、热键和单实例锁；最小化到托盘会明确保留后台进程以支持再次唤起。

## 1.0.1 — 2026-08-18

## 1.0.0 — 2026-08-18

首次发布 Windows 11 中文便携版。

### Added

- 随手记与提示词共用的轻量条目模型。
- 中文即时搜索、收藏置顶、单层分类和回收站。
- `{{变量}}` 提示词填写与一键复制。
- 350 ms 自动保存、原子 JSON、每日备份和损坏恢复。
- 独立置顶小窗、托盘、全局快捷键和单实例唤起。
- 完整中文界面、微软拼音 IME 与 UI Automation 支持。

### Distribution

- 单个根目录 `SeerNote.exe`，无需安装器或第三方运行时 DLL。
- 数据仅写入程序同目录 `data/`，关闭后可整体复制迁移。
- 无账号、网络、遥测或订阅；按 MIT License 发布。
